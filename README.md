# 🏚️ Beylikdüzü Korku Evi - Resmi Web Sitesi

Beylikdüzü Korku Evi'nin resmi web sitesi. 10 yıllık tecrübe ile gerçek zamanlı korku deneyimi sunan profesyonel korku evi işletmemizin online platformu.

## 🎭 Özellikler

- **Modern ve Responsive Tasarım**: Tüm cihazlarda mükemmel görünüm
- **Hikaye Anlatımı**: Yarım kalan ritüelin hikayesi
- **Galeri**: Atmosfer ve deneyim fotoğrafları
- **Instagram Entegrasyonu**: Canlı sosyal medya paylaşımları
- **Rezervasyon Sistemi**: WhatsApp üzerinden hızlı iletişim
- **İnteraktif Harita**: Google Maps entegrasyonu
- **SEO Optimize**: Arama motorları için optimize edilmiş

## 🚀 Teknolojiler

- **HTML5**: Semantic ve erişilebilir yapı
- **CSS3**: Modern animasyonlar ve responsive tasarım
- **JavaScript**: Dinamik menü ve smooth scroll
- **Express.js**: Statik site sunucusu
- **Node.js**: Backend altyapısı

## 📂 Proje Yapısı

```
/app/
├── public/                 # Statik dosyalar
│   ├── index.html         # Ana sayfa
│   ├── styles.css         # Tüm stiller
│   └── script.js          # JavaScript işlevleri
├── server.js              # Express sunucusu
└── package.json           # Bağımlılıklar
```
